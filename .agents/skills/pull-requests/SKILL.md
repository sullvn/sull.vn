## Replying to Review Comments

Reply to a review comment with a robot emoji, then a quote.

The quote is a simple reference to the commit that settled the comment:

```md
🤖

> Fixed in adf4asf
```

Or it's a concise explanation with little jargon:

```md
🤖

> Kept this as it is. Simulations showed the other values learned no better.
```
